A **procedure** says how an approved thing is done, step by step, so a person or their helper can do it without the
author in the room. Psanctuary Church writes its procedures in a private repository for its members; this public
copy receives **only the pages an officer has listed** for visitors.

**Nothing is published here yet.** The list of pages that may come here is empty until an officer adds a line to it.
When they do, the page arrives on its own, together with a file named `SYNCED-FROM-….txt` that lists every page
this copy received. Pages are never edited here by hand; a correction is made in the church's own repository and
arrives with the next update.

# Psanctuary Church: procedures, public copy

*The church's standard operating procedures that its officers have chosen to share with visitors.*

A **procedure** says how an approved thing is done, step by step, so a person or their helper can do it without the
author in the room. Psanctuary Church writes its procedures in a private repository for its members; this public
copy receives **only the pages an officer has listed** for visitors.

**Listed, arriving with the first sync.** Since 2026-11-01 the list names the nine procedures every organisation in the
fleet shares, filled in for the church: **SOP-COM-001** *New to GitHub: your first hour* (start there), SOP-OPS-001 to
003 (how a change travels, pull requests, what may go public), SOP-IT-001 to 003 (resolver stalls, the reading room and
your helper, local dashboards) and SOP-GOV-001 and 002 (the Board's door, GitHub collaboration), each with its PDF, the
legend and the icons they draw. They arrive on their own once the copy's key is in place, together with a file named
`SYNCED-FROM-….txt` that lists every page this copy received. Before anything arrives, a machine reads every file,
PDFs included, and stops the copy if anything private shows. Pages are never edited here by hand; a correction is made in the church's own repository and
arrives with the next update.
